## 一、头像

### 候选

| 编号 | 构图 | 一句话 | 适用 |
|---|---|---|---|
| **A** | 三牌斜靠 萬 / 乐 / 筒 | 与启动页 logo 完全同构，品牌延续性最强 | 想要「一眼认出是同一个游戏」 |
| **B** | 双牌前后叠 + 红印章「对」 | 直译玩法「碰个对」 | 想让头像说明玩法 |
| **C** | 单牌「乐」+ 红印章「对」 | 牌面最大、最闲适，**牌面用的是游戏自有的装饰字牌，不指向任何一种具体牌型** | **推荐** |
| **D** | 单牌「發」+ 红印章「对」 | 牌类里最标志性的一个字 | 想让不认识的人一眼看出是牌类游戏 |

**C 和 D 只差一个字，但方向相反**：
- **C（乐）** —— 「乐」是本作自有的装饰字牌（首页三张展示牌之一），不带任何具体牌型的指向，
  配合「不出现『麻将』二字」的整体口径更一致。**我推荐 C。**
- **D（發）** —— 识别度最高，但「發」是最典型的麻将字牌，等于用图形把「麻将」写回脸上。
  如果规避的只是**文字**，D 没问题；如果连**观感**上也不想被归到棋牌，就用 C。

对比图见 `icon-sheet.png`（512 / 144 / 64 / 40 四档缩略），**放进微信列表里的真实观感**见
`icon-preview.png`。**40px 档是判断依据**：A、B 在这一档只剩一个白色团块，C、D 的「乐」「發」+
红印章仍能分辨——微信的会话列表、搜索结果、分享卡片里图标就是这么大。

### 文件与上传口径

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `icon-<候选>-512.png` | 512×512，圆角方形 + 四角透明 | 微信小游戏「游戏图标」素材（PNG，<200KB） |
| `icon-<候选>-144.png` | 144×144，满幅方图 | 后台「小程序头像」（PNG，<2MB，圆角由微信自己裁） |
| `icon-sheet.png` | 对比图 | 选型用，不上传 |
| `icon-preview.png` | 列表观感对照 | 选型用，不上传 |

后台头像一年可改 5 次；游戏图标素材随版本提交。两个文件都是从同一张 1024 母版降采样出来的，
所以缩到 144 不会糊。

### 设计说明

- **底**：玉色方章（`jadeLight → jade → jadeDeep` 竖向渐变 + 左上暖光 + 底部庭院弧线 + 暗角），
  外圈一道金线——和游戏里匾额 / 面板的「金边」是同一个元素。
- **牌**：象牙牌身（白 → `#FDF8E4` → `#F0E7CC`）+ 底部花色脚 + **实心向下投影**（不是模糊阴影），
  与牌桌上一模一样。
- **印章**：红底白字「对」，来自首页标题旁那枚竖排印章。
- **没有 emoji、没有渐变噪点、没有多余装饰**：整张图只有牌、印章、金线三种元素。

## 二、名称

微信小游戏名称**不可与已有小游戏重名**，且发布前只有 2 次修改机会（之后再改要重新微信认证）。
**先拿候选名去后台「名称查重」，再定。**

### 候选（按推荐度）

| 名称 | 字数 | 说明 | 代价 |
|---|---|---|---|
| **推牌小馆** | 4 | 「推牌」= 核心操作（按住整段牌推着滑走），也是牌桌通用词；「小馆」保留原名里最好的那部分 | 「推牌」对非玩家略生僻 |
| **碰个对** | 3 | 直接来自游戏内 slogan「推一推 · 碰个对」，口语、好记、好搜 | 不点明是牌类游戏 |
| **一筒小馆** | 4 | 用最标志性的牌面做识别，画面感强 | 「一筒」对非玩家无意义 |
| **玉牌小馆** | 4 | 「玉」呼应绿玉庭院的视觉主色，与头像的玉色底同源 | 略抽象 |
| **对对消** | 3 | 首页那枚红印章上的三个字，玩法直译 | **纯描述性**：查重容易不通，「XX 消」家族也容易被商标投诉 |

**我的排序：推牌小馆 > 碰个对 > 一筒小馆 > 玉牌小馆 > 对对消。**
「推牌小馆」同时满足三件事：不含「麻将」、有显著性（不像「对对消」那样纯描述）、
保留了原名的场景感。

> ⚠️ **但这份排序只考虑了「名字好不好」，没有考虑「用户搜不搜得到」。**
> 按搜索重排的结论在 **§六**，最终建议以那一节为准——两者的取舍不一样。
>
> **本节与 §六 都只是推演过程。最终定名：快乐推麻对对消**（用户 2026-10-15 拍板，见文首）。

**不要用**：「消消乐 / 消消看 / 连连看」家族——「消消乐」是乐元素持有的注册商标，撞上就是侵权投诉。

### 简称（2–8 字符，选填）

- 推牌小馆 → **推牌**
- 碰个对 → **碰对**
- 一筒小馆 → **一筒**

## 三、介绍

后台填写时以页面提示为准（小程序介绍上限 120 字符；上架素材里的「游戏介绍」口径是 30–500 字）。

**三条写作约束**（本轮重写口径）：

1. **不官方**——不用「本游戏是一款……采用……玩法」这种说明书腔，说人话，像跟朋友推荐；
2. **不写玩法道具**——不出现提示 / 洗牌 / 撤销 / 星级 / 步数 / 冰牌 / 花牌 / 锁轨这类词，
   也不解释规则；只讲**氛围、感受、什么时候玩**；
3. **埋易搜的词**——名称里没有「消除」，所以简介要替名称补上搜索词。

### 1. 一句话（搜索、分享卡片用，≤ 30 字）

**搜索版**（25 字符，含 4 个搜索词）

> 绿玉庭院里的消除小游戏，安静、解压，随时能来一局。

**品牌版**（不带搜索词，用在分享卡片上）

> 推一推，碰个对——庭院里的牌局，100 关不重样。

### 2. 后台「小程序介绍」（120 字内）

**★ 推荐**（67 字符，覆盖 14 个搜索词，口语但不失分寸）

> 绿玉庭院，木桌清茶。一款很安静的牌类消除小游戏：益智、休闲、解压，不用联网也不氪金。

**A · 氛围版**（67 字符，12 个搜索词，更安静一点）

## 五、认证 / 备案：游戏内名称与注册名不一致会怎样

**结论三句话：**

1. **微信认证 —— 不受影响。** 认证核的是主体资质和名称本身（侵权、受限词、前置审批领域），
   不检查游戏内的任何文字。
2. **小程序备案（工信部）—— 不直接看游戏内文字，但改名本身必须走备案变更。**
   它比对的是「备案登记名称 ↔ 后台小程序名称」，要求**完全一致，含标点与空格，差一个字符就驳回**；
   不一致会被工信部数据比对扫出来，**7 日内**不更新就限制搜索、限制新增用户注册。
3. **小游戏备案（前置审批的「游戏内容介绍」）—— 直接卡游戏内名称，是必驳项。**
   官方要求提交的截图里**必须出现游戏名称，且与备案名称一致**。现在首页写的是「麻将」，
   备案名会是新名 —— 对不上，直接驳回。

### 三条链路对照

| 链路 | 审核方 | 比对的是什么 | 游戏内文字有影响吗 |
|---|---|---|---|
| 微信认证 | 腾讯 | 主体资质 + 名称合规性 | **否** |
| 小程序备案 | 工信部 / 通信管理局 | 备案名称 ↔ 后台小程序名称（**完全一致**） | 否（但改名要走变更备案） |
| 小游戏备案（游戏内容介绍） | 平台初审 → 主管部门 | 提审游戏名称 ↔ 线上游戏名称 ↔ **游戏截图里的名称** | **是，必驳项** |

### 官方原文（可直接引用）

- 「小程序备案名称**必须与微信小程序实际名称完全一致，包括标点符号、空格等字符**；若存在差异，
  **即使仅一个字符不同，也会导致备案审核失败**。」——微信开放社区运营专员答复
- 「长时间未按要求完成工信备案或者备案后改名、改主体相关行为导致**小程序信息和备案信息长时间不一致**，
  将有可能影响你的小游戏正常运营，包括但不限于**限制搜索、限制新增用户注册**。」
  ——《小游戏备案》官方指引
- 「确保清晰、完整、真实介绍你所备案的小游戏内容……并上传对应截图，截图需保持尺寸、版本一致，
  **其中玩法首张图必须包含『健康游戏忠告、适龄提示、游戏名称』三种信息**。」
  ——《小游戏备案》官方指引 · 提交要求
- 「审批要求**游戏名称、账号主体在任何阶段都保持与当前提审游戏名称、提审账号主体一致**，否则会导致驳回。」
  ——《小游戏备案前置审批指引》
- 同口径的另一平台细则写得更直白：截图「应包含**登录界面（登录界面须有游戏名称）**、游戏主界面、
  主要功能玩法界面……」，负例第一条就是「**首页无名称**」。

### 本项目要补的（现在一样都没有）

我按代码核过了，三样都缺：

| 要求 | 现状 | 要做的 |

### 一个额外的雷（待后台确认）

第三方资料提到：**个人主体的小游戏二级类目暂不支持「文化互动 / 角色类 / 牌类」，只能选休闲益智等轻休闲**；
且棋牌类（含捕鱼）须有版号。本作是单人消除益智、无对局无社交无博彩，应走「休闲益智」——
但**名称和截图里如果牌类指向太强，容易被判到牌类**。这条不是微信官方文档原文，请以后台实际类目
列表为准；不过它和前面的结论是同一个方向：**去「麻将」化不只是名称问题，是整条上架链路的一致性要求。**

## 六、名称 × 微信搜索（最终定名的依据）

### 1. 搜索排序看什么（官方口径）

微信小游戏开发者学院《小游戏触达能力使用指南》给出的排序因素：

| 因素 | 说明 |
|---|---|
| **搜索词相关性** | **只有与搜索词相关联的账号才可能被召回**；相关性计算**包含小游戏的名称、简介** |
| 用户画像 | 同一个搜索词，不同用户看到的结果不同（个性化） |
| 游戏留存 | 大盘留存、**搜索渠道留存**都进排序 |
| 主体信用分 | 有处罚记录、信用分低 → 排序靠后 |

两条官方明确说的「别指望」：
- **「蹭 IP、热度基本无效」**——名称审核很严；就算名称过了，质量/留存低照样被监控，混淆或侵权会被处罚。
- 搜索结果有 **24 小时缓存**：当天上线当天搜不到，第二天才出现。

### 2. 从机制推出的三条设计原则

1. **名称里必须含一个「用户真的会输入的完整词」**——不是半个词。
   官方社区有个真实案例：小游戏叫「拯救大橘」，用户搜「拯救」「大橘」「拯救大」**都搜不到**，
   连简介里的「三消」「消除」也搜不到，**只能全名搜**。所以冷启动阶段，名称是唯一可靠的相关性来源。
2. **核心词前置**。多篇实操资料一致：把最关键、最常使用的词放在名称前面，名称控制在 10 字内
   （太长会被截断、权重分散）。
3. **品牌词要有显著性**。名称审核会卡「广义归纳、普遍且不具识别性的词汇」——
   两个通用词硬拼（比如「消除游戏」）容易被拒，也记不住。

### 3. 一条必须知道的法律边界

**「消消乐」不能碰，连当宣传语用都不行。** 北京知识产权法院终审（乐元素/乐浣 诉 沈阳纵艺）：

- 「快乐消消乐」「泡泡消消乐」「糖果消消乐」被判侵权——**只要名称包含「消消乐」字样即构成近似**；
- 被告辩称「消消乐」已成通用名称，**法院不予采信**；
- 把「消消乐」当**游戏类型名称**用在宣传语里，同样构成侵权；
- 判赔 **200 万元** + 合理开支 20 万元。

同一份判决书里，法院写明了这个品类的通用名称是什么——**「消除」或「三消」**：

> 「涉案游戏的通用名称通常为『消除』或『三消』。」

**这一句直接给了答案**：名称里要用的品类词是**「消除」**（法院认可的通用名称、用户会搜、无商标风险），
不是「消消乐」。

### 4. 按搜索重排的候选

| 名称 | 冷用户搜什么能命中 | 品牌词显著性 | 判断 |
|---|---|---|---|
| **消除小馆** | **消除**（核心词前置） | 「小馆」偏通用 | **推荐**：搜索命中最好，且延续原名的「小馆」 |
| **对对消除** | **消除** | 「对对」与首页印章「对对消」同源 | 品牌一致性最强（印章就是名称前三个字） |
| **推牌消除** | **消除** | 「推牌」最有显著性 | 显著性最好，但读起来略硬 |
| **庭院消除** | **消除** | 「庭院」呼应绿玉庭院的视觉 | 画面感强 |
| ~~推牌小馆~~ | 只有全名 | 高 | 冷用户搜不到——**搜索上等于放弃自然流量** |
| ~~对对消~~ | 只有全名 | 中 | 同上；且不含「消除」二字，搜「消除」不会召回 |

**结论：定名从「推牌小馆」改为「消除小馆」或「对对消除」。**
前一份排序（§二）只看名字好不好，这一节看的是能不能被搜到——**「推牌小馆」好看但搜不到**，
冷启动没有自然流量，这个代价比名字平淡大得多。

> **最终定名：快乐推麻对对消**（用户 2026-10-15 拍板）。
> 它把「对对消」放在了名称尾部——正好是首页印章那三个字，大字与印章连读即完整名；
> 但**不含「消除」**，所以后台那 10 个搜索关键词是它能不能被搜到的关键，务必配足（见下一小节）。

（选「消除小馆」还是「对对消除」，取决于你要不要保留印章「对对消」的品牌一致性——
选后者的话，首页大字用「消除」、印章保留「对对消」，名称和印章就是同一套字。）

### 5. 名称之外，权重可能更高的六件事

名称只是相关性的一部分。官方明确说留存和信用分进排序，所以这些别落下：

| 动作 | 位置 | 价值 |
|---|---|---|
| **配置搜索关键词（最多 10 个）** | 后台「推广」模块 | 覆盖名称覆盖不到的长尾词；**一个月只能改 3 次**，一次想清楚 |
| **配置运营素材（封面图）** | 后台 → 游戏设置 → 运营素材配置 | 官方实测：搜索结果里**展示封面图的点击率高 7%** |
| **接入好友排行榜** | 后台 → 游戏设置 → 排行榜配置（需按规范上报数据） | 官方实测：**展示排行榜的点击率高 23.7%**，是投入产出比最高的一项 |
| **保留存** | 产品侧 | 大盘留存、搜索渠道留存直接进排序——「搜索进来的人玩不玩得下去」是排序因子 |
| **别被处罚** | 运营侧 | 主体信用分低会压排序 |
| **尽早注册** | 后台 | 多篇资料一致：注册时间越早，同等质量下排序越有优势；好词先占坑 |

**10 个搜索关键词的建议**（避开「麻将」与「消消乐」家族）：

```
消除 / 消除游戏 / 消除小游戏 / 三消 / 消消
益智游戏 / 休闲小游戏 / 解压游戏 / 单机小游戏 / 闯关游戏
```

（前 5 个是品类词，后 5 个是场景词。别堆砌无关词，会被判低质降权。）
