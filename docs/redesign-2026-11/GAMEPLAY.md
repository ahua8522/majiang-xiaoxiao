# 快乐推麻对对消 · 玩法梳理

2026-11-05 · 本轮先确定玩法，再迁移正式关卡。广告等开通流量主后再评估。

## 玩家只需要记住什么

**点两张相邻同牌，或者推一行、一列，让同牌碰头。**

麻将牌、万筒条和字牌都保留；不需要懂胡牌、清一色、将将胡等知识。主线的相邻是上下左右。滑动是所在连续轨道循环移位，空格也一起移动；木块和缺口把轨道隔开。没有消除的推移也可以用来摆位置。

一局的乐趣是：看目标 → 找对子 → 选择先消哪对、往哪里推 → 触发机关 → 完成目标。目标时长先按 1–3 分钟设计，后期精巧关 3–5 分钟，需用试玩结果调整。

## 三类过关目标

每关只强调一个主目标，始终放在牌桌上方，以图标和数量表示。

| 目标 | 玩家看到什么 | 怎样完成 | 多出来的选择 |
| --- | --- | --- | --- |
| 清空牌桌 | 麻将图标 + 剩余张数 | 收走所有牌 | 先消哪一对，才能露出或排好后面的对子 |
| 收集目标 | 两种牌的实物小图 + 各自数量 | 收齐指定牌，不要求清空 | 先消挡路牌，还是直接凑目标；非目标牌照常能消 |
| 花圃开花 | 花朵图标 + 已开/总数 | 在所有标记地格上真正消掉牌 | 把对子送到花圃处再消，不能只挑眼前容易消的 |

例如：两张四条分别落在一个花圃和一个普通格上，消除后该花圃开花；两张都在花圃上，两处都开花。**花圃固定在地上，不跟牌走；只破冰不算开花。** 收集和花圃目标达成就过关，不必再清剩余牌；最后一步达标也算赢。

## 机关怎样增加变化

| 机制 | 一句话说明 | 玩家要考虑什么 | 本轮安排 |
| --- | --- | --- | --- |
| 自动连消 | 一次推移能接连消掉多对 | 推哪条线更划算 | 保留核心爽点；一次推移的全部连消只计一步 |
| 叠层 | 收走上面的牌，露出下面的牌 | 先揭哪一叠 | 保留，先教两层，画出侧边厚度；前期不给三层 |
| 冰 | 先配对破冰，再配对收牌 | 先解冰还是先整理路线 | 保留并计划简化，先用薄冰；具体新旧区别见下文 |
| 木块/锁轨/箭头 | 有的路线被隔开或只能单向推 | 从哪条路线把牌送过去 | 保留，逐个教；不可移动的原因直接画在轨道上 |
| 花圃 | 在指定位置消牌就开花 | 消除发生在哪里 | 第一批新增，已有可玩样例 |
| 灵感充能 | 每消一对攒一格，四格换一次提示 | 正常游玩也能获得帮助 | 第一批新增，已有样例；不要求限时连续消除 |
| 钥匙开门 | 收走带钥匙的指定一对，打开对应门 | 先开哪条通路 | 第二批；钥匙用牌外标记，保留麻将正面 |
| 转盘移位 | 按一下转盘，把圈出的四格转 90° | 用一次旋转重新配对 | 第二批；明确圈定范围，按一次计一步，给落位预览 |

薄冰的正式改版建议：两张底层图案相同即可配对。若任一张覆冰，此次削去两边各一层已有的冰，两张牌都留下；两边都无冰时才能成对收走。这样不会因为冰厚不同让同款牌完全不能互动，也不会留下单张。**这是待实现规则；当前正式版和试玩的冰样例仍要求同图案、同冰层数。**

保留现有百搭作为后续帮助牌，先不和新手基础规则同时讲。鞭炮、厚冰、三层叠牌、复杂解锁晚些整理，不把所有已有机制都塞进首版。

## 去掉和收拢哪些内容

- 去掉清一色、将将胡、幺九、断门及组合限制，牌面不再因为关卡术语变成不能配的“哑弹”。
- “三元齐、八花齐、清龙”改为直接展示要收的牌和数量，不让玩家记术语。
- 普通关最多组合两类机关；新机制首次出现时只教这一种。连续几关只增加冰厚和牌量，不算好的难度设计。
- 主线先取消强制倒计时。前几关不限步，中期再引入宽松步数；星级用于挑战自己，不阻挡下一关。
- 独立挑战暂不扩充。它目前是另一套“整行列循环、同线隔空配对、必须产生消除才允许移动”的规则，而且第二盘就从 5×5 跳到 14×10。后续单独重做小盘到大盘的曲线，并明确教学，不与主线混讲。

## 前 16 关怎么教

这是重新编排的建议，尚未写回现有 224 关表。

| 关卡 | 当次学习/变化 | 设计要求 |
| --- | --- | --- |
| 1 | 点两张相邻同牌 | 4×4，小牌池；首对高亮，一次演示，无失败步数 |
| 2 | 横向推一行 | 只需一次明确推移就能见到消除；画落位影子 |
| 3 | 纵向推一列 | 保留上一关知识，只新增纵推 |
| 4 | 自己清空一桌 | 复习；一推多对的小惊喜，不添机关 |
| 5–6 | 两层叠牌 | 第 5 关露牌演示，第 6 关选择先消哪叠 |
| 7–8 | 薄冰 | 先教破冰不收牌，再给“整理位置后破冰”的解法 |
| 9–10 | 花圃开花 | 从 2 个花圃到 4 个；不同时加冰或叠层 |
| 11–12 | 收集目标 | 先一种，再两种；演示非目标牌也能消 |
| 13 | 灵感提示 | 消四对亮一次提示；无倒计时，不因思考而断连 |
| 14 | 木块改道 | 第一次教轨道被分段；只有木块这一种障碍 |
| 15 | 熟悉机关的组合 | 花圃 + 两层叠牌，强调消除的位置 |
| 16 | 章节收尾 | 清晰主目标、一次明显连消、领取章印；不靠牌量暴涨 |

后续按“教学 → 练习 → 一个组合关 → 放松关”循环。主线先从 4×4 过渡到 5×6，再评估 6×7；牌面和点击范围优先于大棋盘。首轮试玩关注玩家哪里停住、哪里点错、是否理解目标，用本机测试记录即可。

## 帮助、失败与长期收获

- 底部只放 **提示 / 撤销 / 重开**，小图标配两个字；只在需要时显示一句动态指导，不放三组副标题。
- 正式迁移建议统一到一个“提示”入口：优先使用攒满的灵感，其次使用每局免费提示；没有找到有效路线就不扣资源。充能到顶保留，不自动花掉；不用提示也能通关。
- 充能按实际收走的对数累计；破冰和单纯推位不给能量，慢慢思考不会清空能量。撤销同时回退目标和能量，避免反复撤销刷奖励。
- 前期不限步可以自由撤销；有限步关沿用正式版“只还原牌面，不退已用步数”，按钮旁首次说明一次。失败页允许免费重开；不能用一个实际上无法解除失败的“撤销”作为续局承诺。
- 试玩为便于比较，提示不限次、所有样例都有充能，撤销会退步数。这些是试玩设置，正式资源和失败规则仍需迁移时统一。
- 首次通关收花笺，章节完成解锁桌布或小花盆；重玩改善星级。装饰不改变牌面规则，不堆体力、抽卡、签到补签等额外系统。
- 关卡、装饰和存档都放本机；暂不做联网活动、排行榜或跨设备同步。广告入口与奖励数值等流量主开通后再讨论，本轮不设计靠广告才能过的关。
