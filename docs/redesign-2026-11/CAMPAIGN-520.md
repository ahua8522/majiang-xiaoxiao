# 520 关玩法与关卡设计

麻将身份、备案名称和「相邻同牌配对 + 整行整列循环推移」保留。主线重编为 26 章，每章 20 关；取消清一色、将将胡、幺九、断门这些禁消规则。

## 玩家怎么玩

1. 先看顶栏：清台、开花、浇水、花苞，或带真实牌面的收集清单。
2. 相邻同牌可直接点消；拖动一行/列，松手后自动处理相邻对子和叠层连消。
3. 机关决定顺序。锁轨只限制沿它本身方向推，垂直推移与点消仍可用。
4. 完成目标即可过关。每章首次进入展示两句教学，读过后不再反复弹出。

## 机关规则

| 机关 | 生效方式 |
|---|---|
| 双层 / 三层牌 | 消掉上层才露出下层，推移会移动整叠。 |
| 冰 / 厚冰 | 同款可跨冰层配对；任意一侧有冰时，只各碎一层，两张都留下，下一次才收走。 |
| 花圃 | 在标记格真正收走牌才开花；格子不跟牌移动。 |
| 水滴 | 在标记格上下左右收牌即可浇水，自身与斜角不计。 |
| 花苞 | 标记格在两个不同操作中收牌才完成，同一次连消多波仅记一次。 |
| 钥匙锁 | 收到两张带钥匙的目标牌，开启对应行/列；破冰不算收到钥匙。 |
| 灵感充能 | 每真正消一对充一格，四格换一次提示，满格不溢存；撤销不能返还已花掉的能量。 |
| 木块 / 缺口 | 截断推移路线，制造绕行。 |
| 单向轨 / 固定锁 | 箭头指示可推方向，锁指示不可沿该方向推。 |
| 计数解锁 | 收牌对数达到锁上门槛后开放轨道。 |
| 百搭花牌 | 可配任意牌；注意别让其他牌失去搭子。 |
| 爆竹 | 配对震碎邻格冰牌，并带动全桌同款冰牌各碎一层。 |
| 收集清单 | 列出的每种牌各收两张；其余麻将正常配对，没有花色禁消。 |

## 大小与节奏

本批最大 **8 列 × 10 行**，不是规则引擎硬上限。前期从 4×3 起步，中期引入 6×7、6×8、7×8，后期有 8×8、8×9、8×10。每章第 9、15 关安排紧凑、无步数限制的休息关；章末常用较大盘。主线均无倒计时。

每关固定种子与盘面指纹，重开同一盘才能学习路线。520 个盘面各不相同，生成时重放真实机关状态验证目标可达，再由 Session 逐关验证参考路线不会中途耗尽步数。尺寸、牌种数、堆叠、机关组合共同变化；难度仍需真人试玩调节，自动验证只证明可玩性。

## 辅助、存档与声音

- 下方只留「提示 / 撤销 / 重开」。可安全重排的关在暂停菜单放洗牌；花圃、水滴、花苞关禁止重排，保留撤销和重开。
- 每局三次免费提示、两次洗牌；免费重开恢复额度。提示有结果才扣次数或能量，搜索超预算会明确显示没找到短路线。
- 撤销恢复牌桌、机关和收集进度，已花的步数与提示额度不退。限步失败可免费续两次（+3、+1），无广告接入。
- 星级只看步数，提示不扣星；当前星级参考清台证书步数，目标关会相对宽松。章节按通关进度解锁，不设刷星门槛。
- 全部本地存储，无服务器。旧版本保留已解锁关号与设置，旧成绩和旧牌桌归档，避免套到重编后的关卡。新版本保存机关状态及验证过的剩余解题路线。
- 首页与对局各一首 48 秒循环音乐，12 种反馈音效。音乐与音效分别保存开关，首次触摸解锁播放，切后台暂停。

源码已同步到正式 Cocos 与 H5 演示；五模式原型保留作设计历史。逐关数据见 [关卡全量表](../关卡全量表.md)。广告待开通流量主后另行设计。
