# 快乐推麻对对消 · 音乐与音效方案

2026-11-05 · [直接试听](sound-lab.html) · [30 秒合辑](audio/listening-study.mp3)

## 听起来是什么感觉

**像在明亮、安静的房间里轻轻碰麻将。** 背景音乐柔和、留白，操作音短、清楚、有一点实体牌的重量。麻将的识别来自牌面和碰牌声；音乐不用茶馆叫卖、锣鼓或密集民乐来强调地域。

本次已制作 **2 段背景音乐、12 个音效和 1 段试听合辑**。全部来自仓库内的原创音序和声音合成代码，无外部采样、配音或联网依赖。这是可评估方向的声音草稿：琴键、木质敲击和麻将质感由合成模拟，尚不是实录乐器或最终母带。需要在手机扬声器、耳机上试听后调整音色和混音。

## 背景音乐

| 场景 | 曲目 | 结构 | 听感和用途 |
| --- | --- | --- | --- |
| 首页、地图、收藏 | 晴日小憩 | 80 BPM，4/4，D 大调音阶，16 小节 / 48 秒循环 | 柔和琴键、少量木质弹拨/敲击、轻低音；有旋律但不抢界面注意力 |
| 对局 | 轻轻推一推 | 同一和声体系，16 小节 / 48 秒循环 | 更少音符，旋律降低八度，留出选牌、破冰与消除声的位置 |

进入对局时约 0.45 秒淡入新曲；返回首页切回首页曲。开设置或暂停时降低音乐音量，关闭后恢复。切后台暂停音频，回来接着播，不从头抢播；失败时保留平静的背景，不加紧迫鼓点和倒计时滴答。

## 音效与触发

| 事件 | 文件 | 时长 | 声音设计 / 触发条件 |
| --- | --- | --- | --- |
| 选牌 | `tap.mp3` | 0.16 秒 | 轻而短的实体牌接触感；只在选择改变时响 |
| 推移落位 | `slide.mp3` | 0.23 秒 | 柔和摩擦接轻落位；成功提交一次滑动响一次，拖动中不连响 |
| 收走一对 | `match.mp3` | 0.42 秒 | 两次微错开的碰牌，短尾音 |
| 多对消除 | `combo.mp3` | 0.75 秒 | 碰牌加短上行三音；同一步多对用一次，避免叠十几个碰撞 |
| 破冰 | `ice.mp3` | 0.42 秒 | 细碎、收短的裂冰，不用刺耳玻璃爆炸 |
| 花圃开放 | `bloom.mp3` | 0.80 秒 | 三个向上展开的柔和音；同一步多朵只响一次 |
| 灵感充满 | `charge.mp3` | 0.85 秒 | 四音点亮；只在能量从不足变满时响 |
| 提示成功 | `hint.mp3` | 0.65 秒 | 两个轻音，跟随高亮；没找到路线不响成功音 |
| 撤销 | `undo.mp3` | 0.30 秒 | 低一点的回落碰牌；不重播被撤销动作的奖励音 |
| 通关 | `win.mp3` | 1.80 秒 | 一句温暖的上行收束；每次真正通关响一次 |
| 暂未完成 | `lose.mp3` | 1.25 秒 | 两个缓和的回落音；不使用警报或责备性语音 |
| 界面切换 | `ui.mp3` | 0.12 秒 | 比选牌更轻的触点音，保持克制 |

同时发生多个奖励时，对局只选一个重点结果声：**通关/失败 → 开花 → 充满 → 破冰 → 多对消除 → 普通消除**，可叠一声推移落位。重画界面、打开已完成关的结算、撤销不再次播放成功奖励。

## 音频行为与预算

- 设计稿已接入 Web Audio；第一次点击或键盘操作之后启动。音乐与音效是两个独立开关，保存到设计稿自己的本机存储键；“减少动态效果”不影响声音。
- 同类音效最短间隔 75ms，同时最多 6 个音效；解码晚于动作 1 秒的声音丢弃。关闭音效和切后台时清掉未播/正在播的短音，回来不补播过期奖励。
- 音乐底稿约 −25 / −27 dBFS RMS，运行时音乐增益 0.38，弹窗降到 0.10；效果草稿约 −23 至 −25 dBFS RMS，并留峰值余量。总线另有 0.75 增益与温和压缩。这里是初始混音值，不是正式响度标准或已完成的手机听感结论。
- 音频为 32kHz 双声道 MP3；每段音乐约 470KB，12 个短音合计约 110KB，游戏实际嵌入约 1.02MiB。30 秒合辑约 353KB，只用于评审，不放游戏包。
- 独立设计稿把音乐与音效一起嵌进 HTML，可断网运行。两段音乐解码后在 32kHz 约占 23.4MiB；浏览器会重采样到音频上下文频率，在 48kHz 约占 35.2MiB。正式版应控制当前/下一首缓存，在低内存设备上评估释放。
- `make-audio.py` 保存音符、音色、时序与确定性随机种子；运行 `python docs/redesign-2026-11/make-audio.py` 可重建 MP3。需要 NumPy、SciPy 和 FFmpeg；WAV 中间文件仅保存在忽略的 `temp/audio-masters/`。

## 正式小游戏接入

正式 Cocos 已通过 `view/AudioBus.ts` 接入两首音乐与 12 种音效，H5 主线使用 Web Audio 播放同一批资源。声音跟随真实操作与目标进度变化，重绘不重播；音乐与音效分别保存开关，切后台暂停，异步加载完成后也会再次检查静音状态。Cocos 使用一个音乐通道和最多六个效果通道，音乐音量 0.28、结算/暂停时 0.10，效果音量 0.7。

14 个 MP3 随本地资源包提供，无需服务器。评审合辑、WAV 母版及 base64 HTML 不进入微信包。已验证 Cocos 浏览器预览中的首次交互与播放、没有资源加载错误；手机系统静音、长时间循环、低端设备、耳机和外放的听感仍需真机试听。
