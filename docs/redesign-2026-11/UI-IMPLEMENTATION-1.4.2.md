# 1.4.2 首页与大棋盘布局

本次延续「晴日花园」，调整首页入口、主线和独立挑战的空间分配、按钮材质。520 关、机关规则、麻将牌种、存档与离线运行方式保持原样。

## 首页

- 移除首页底部四项导航，新增「游园选关」按钮，与「机关工坊」「我的收藏」并列。
- 主入口仍为「开桌消一局／继续这一桌」。其他页面保留原来的返回和导航路径。
- `sunnyBannerArea()` 定义底部 120 设计单位的横幅区域，距底部 24 单位；按钮至少留出 22 单位间隔。当前只留白，没有广告 SDK、广告请求或假广告按钮。以后接入时仍需以广告实际高度及设备底部安全区重新定位。

## 牌桌

- 独立挑战删除大目标卡和重复说明，只保留标题，以及一行「剩余牌数／已用步数」。
- 主线把章节、关数并在标题中；目标和步数并为一张紧凑状态条。收集目标保留牌面及进度标记。
- 主线和挑战共用牌桌尺寸计算，同时考虑行列数、可用高度、桌沿和底部工具。仍保留微信胶囊安全距离。
- 减薄桌沿，牌身占单格比例由 84% 增至 90%，保持 1∶1.24 牌格比例；主线为锁轨徽标额外保留横向空间。
- 底部保持三个短按钮；灵感充能改为提示按钮中的四段小刻度。

## 按钮

- 普通按钮及卡片改为瓷白，配细边线和较薄底边。
- 杏桃／绿色按钮保留完整连续渐变。Cocos 纹理只沿水平方向切片，竖向整体缩放，消除九宫格造成的渐变分段。
- 继续使用固定图集，不按按钮尺寸动态创建纹理。

## 验证

- Cocos 和 H5 类型检查通过；6 项视图／转译回归检查通过。
- H5 与原生导航测试通过：继续游戏、设置、重开确认、选关翻页、工坊隔离和收藏切换。
- 主线 61、161、181、221、480、520 关在三种尺寸检查通过；H5 在 390 宽度实际走完解法，原生验证前三次触摸动作。
- 独立挑战第 2／50 盘在 320×568、390×844、430×932 下分别验证三次真实拖动，检查顶部安全距离、牌桌与工具分离、首页横幅区域无按钮。
- 修正了原生测试环境：Creator 默认固定 393 像素宽，单改浏览器窗口会裁边。测试现在同步修改预览容器和引擎帧尺寸，并断言画布边界。
- 计量含预览工具条占用的 50 CSS 像素，并额外模拟 128 设计单位的微信顶部安全距离。与同尺寸旧布局相比，可见牌身宽度增幅如下；这不是对所有真机字号或触控体验的保证。

| 测试窗口 | 挑战牌身宽度 | 相对 1.4.1 增幅 |
| --- | ---: | ---: |
| 320×568 | 15.1 CSS px | 37.2% |
| 390×844 | 27.3 CSS px | 30.6% |
| 430×932 | 30.5 CSS px | 30.4% |

极短小屏完整显示 14 行时仍受物理空间限制；本次没有修改挑战的行列数或加入缩放手势。
