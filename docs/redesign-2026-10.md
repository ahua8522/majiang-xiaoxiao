# 2026-10 实测反馈重设计（v2 玩法 + 视觉修整）

> 来源：用户实机试玩到 50+ 关后的 6 条反馈。设计决策已经用户确认：
> 「乐」= 大厅装饰牌上写「乐」字（非玩法牌面）；新机制 = 冰牌 + 花牌；保持 100 关重排难度曲线。

## 1. 玩法：冰牌（核心引擎，双端共享 core/）

- 牌面编码：冰面牌 face 以 `~` 结尾（如 `5s~`），露出后的原牌就是 `5s`。
- 匹配规则：`partners`/`pairs` 直接按 top face 字符串相等，`5s~` 只与 `5s~` 相配，天然成立。
- 消除语义（`Rules.transition`）：
  - 冰对子第一次 match/slide 连消：两侧各弹出一层并压回去冰后的 face（`5s~` → `5s`）；
    `erased` 记录的 face 是带冰的（消除动画整张淡出即可）。
  - **刚露出的对子不得在同一事务里被连消**（否则冰牌一次移动就没了）：
    chain 循环的 candidates 排除「本次露冰的格子」。
  - 第二次 match 才真正移除。
- 生成（`Generator.construct`）：`LevelDef.ice` = 本关冰对子数；配对放置后随机取 ice 个对子包冰。
  certify 按真实 transition 重放，天然覆盖冰语义。
- 洗牌（`redeal`）：按当前盘面 freq 重建 tokens，冰面成对出现时 freq 为偶数可重排；
  单侧碎冰（奇数）时 redeal 返回 null → 洗牌友好降级（现状逻辑不变）。
- 存档校验（`Session.restore`）：接受 `~` 结尾与花牌 face。

## 2. 玩法：花牌（数据扩充）

- f1..f8 = 春/夏/秋/冬/梅/兰/竹/菊，纯牌种扩充（无特殊规则），牌池 34 → 42。
- 视觉：绿色大字 + 梅红花色脚（脚色新增 flower 色），与字牌（紫脚）区分。
- 关卡曲线：约 51 关起入池，后期花牌占比加大。

## 3. 关卡难度曲线（保持 100 关，author-levels 重新生成）

| 段落 | 盘面 | 机制 |
| --- | --- | --- |
| 1-8 | 3×4 | 4 花色、无障碍或少障碍、scramble 2-4（教学） |
| 9-20 | 3×4~4×5 | 木桩/空洞少量、4-5 花色 |
| 21-35 | 4×5~5×6 | 双层牌位、lockR 首次出现（~25）、6-8 花色 |
| 36-50 | 5×6~6×8 | 8-12 花色、scramble 15-20 |
| 51-65 | 6×8~7×9 | 花牌入池、ice 1-2、lockC 首次出现（~56） |
| 66-82 | 7×9~8×9 | ice 2-4、三层牌位、锁行+锁列组合 |
| 83-100 | 8×9 | 22-30 花色（花牌重）、ice 4-6、多重锁轨、scramble 34-44 |

生成后逐关验证：可清台路线、偶奇色格位完美匹配、棋盘两两不同。

## 4. 牌面美术（h5 tile.ts / cocos art.ts 双端同步）

- **条子**：竹节短线分节（节间留缝 + 竹节横杠），按 n 定行数与长度，行间绝不粘连；
  六条=2 行×3 列、九条=3 行×3 列（中列红），5 条中心红、7 条顶红。一眼可分 6/9。
- **筒子**：固定配色表（废除按索引循环取色）：2=上蓝下红、3=红蓝红斜排、4=蓝红对角、
  5=四绿一红、6=行色 红/绿/蓝、7=顶 1 红 + 下 2×3 绿、8=上 2 行绿下 2 行蓝、9=行色 蓝/红/绿。
- **花牌**：绿色衬线大字 + 花色脚梅红。
- **装饰字牌** `x1/x2/x3`：萬(红)/乐(绿)/筒(蓝) 单大字，仅大厅与加载页使用，不入玩法牌池。
- **冰面**：face 带 `~` 时在牌面上叠霜面（浅蓝描边 + 角晶），双端同一画法；
  cocos TileAtlas 对每个玩法牌面同时烘焙 `face` 与 `face~` 两帧。

## 5. 牌桌交互

- **提示统一顶部横幅**：删除底部 toast（h5 drawToast / cocos toastNode）。
  横幅优先级：拖动预览 > session.message > 默认「轻点配对 / 横竖拖动整段」。
  锁轨拖动失败改走 `Session.notice()`（revision 驱动一次重建，不在 move 里逐帧触发）。
- **锁定轨常驻标识**：`Board.build` 模型增加 `lockedRows/lockedCols`（来自 `levelAt().lockR/lockC`），
  在轨底画半透明木条 + 两端锁钉（h5 直接画；cocos 加 `rail` 9 宫格帧 + 锁图标）。
- **暗格统一**：`#` 木桩与 `.` 空洞渲染同一种暗格（数据模型保留区分）。
- **道具行**：cocos 副标题原来排到按钮脸外（脸底 -46.4，文字底 -56.5）→ icon y+14 / 文案 y-2 / 副标题 y-24。

## 6. 大厅与弹框

- 左上角：头像 + 「第 X 关」，去掉总星数。
- 标题簇下移收紧：「麻将」大字 + 红印章竖排「对对消」三字；副标题紧随。
- 装饰牌：萬/乐/筒 三张大字牌（加大尺寸）。
- 按钮：开始游戏（通栏）+ 关卡选择（通栏拉长），删除「我的进度」入口（进度弹框移入设置）。
- **设置 / 选关 / 进度全部弹框化**（veil + 居中面板 + 关闭钮），底层渲染 returnScreen（首页或牌桌）。
- 选关弹框：未解锁显示「?」与锁，不出现任何总关卡数。
